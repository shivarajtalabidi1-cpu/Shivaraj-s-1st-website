1. Relations and Functions

Important Formulas

Domain = Set of all possible input values.
Range = Set of all possible output values.

(f ∘ g)(x) = f(g(x))
(g ∘ f)(x) = g(f(x))

If f is one-one and onto, then f has an inverse.
f⁻¹(f(x)) = x
Practice:
If f(x) = 2x + 3, find f(4).
Answer: 11

2. Inverse Trigonometric Functions

Important Formulas

sin⁻¹x + cos⁻¹x = π/2

tan⁻¹x + cot⁻¹x = π/2

sin⁻¹(-x) = -sin⁻¹x

cos⁻¹(-x) = π - cos⁻¹x

tan⁻¹(-x) = -tan⁻¹x
Practice:
Find sin⁻¹(1/2).
Answer: π/6

3. Matrices

Important Formulas

(A + B)ᵀ = Aᵀ + Bᵀ

(AB)ᵀ = BᵀAᵀ

(A⁻¹)⁻¹ = A

AA⁻¹ = I

For A = [a b; c d],
|A| = ad - bc
Practice:
Find the determinant of A = [[2, 3], [1, 4]].
Answer: (2 × 4) - (3 × 1) = 5

4. Determinants

Important Formulas

For a 2 × 2 determinant:

|a b|
|c d| = ad - bc

Area of triangle:
Area = 1/2 |x₁(y₂-y₃) + x₂(y₃-y₁) + x₃(y₁-y₂)|
Practice:
Evaluate |3 2; 4 5|.
Answer: 15 - 8 = 7

5. Continuity and Differentiability

Important Formulas

If f is continuous at x = a:

lim x→a f(x) = f(a)

d/dx (xⁿ) = nxⁿ⁻¹

d/dx (sin x) = cos x

d/dx (cos x) = -sin x

d/dx (tan x) = sec²x

d/dx (eˣ) = eˣ

d/dx (ln x) = 1/x
Practice:
Differentiate y = x³.
Answer: dy/dx = 3x²

6. Applications of Derivatives

Important Formulas

Slope of tangent = dy/dx

Increasing function:
f'(x) > 0

Decreasing function:
f'(x) < 0

At a local maximum:
f'(x) = 0

At a local minimum:
f'(x) = 0
Practice:
Find the derivative of f(x) = x² + 5x.
Answer: f'(x) = 2x + 5

7. Integrals

Important Formulas

∫xⁿ dx = xⁿ⁺¹/(n+1) + C, n ≠ -1

∫1/x dx = ln|x| + C

∫eˣ dx = eˣ + C

∫sin x dx = -cos x + C

∫cos x dx = sin x + C

∫sec²x dx = tan x + C
Practice:
Find ∫x² dx.
Answer: x³/3 + C

8. Applications of Integrals

Important Formula

Area under a curve between x = a and x = b:

Area = ∫ₐᵇ y dx
Practice:
Find the area under y = x from x = 0 to x = 2.
Answer: ∫₀² x dx = 2 square units

9. Differential Equations

Important Concepts

Order = Highest order derivative present.

Degree = Power of highest order derivative, when equation is polynomial in derivatives.

For dy/dx = f(x):
y = ∫f(x)dx + C
Practice:
Solve dy/dx = 2x.
Answer: y = x² + C

10. Vector Algebra

Important Formulas

|a| = √(a₁² + a₂² + a₃²)

a · b = |a||b|cos θ

a · b = a₁b₁ + a₂b₂ + a₃b₃

a × b = |a||b|sin θ n̂
Practice:
Find the magnitude of vector a = 3i + 4j.
Answer: √(3² + 4²) = 5

11. Three Dimensional Geometry

Important Formulas

Distance between two points:

d = √[(x₂-x₁)² + (y₂-y₁)² + (z₂-z₁)²]

Section formula:

P = ((mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n), (mz₂+nz₁)/(m+n))
Practice:
Find the distance between (0,0,0) and (3,4,0).
Answer: 5 units

12. Linear Programming

Important Concepts

Objective function:
Z = ax + by

Constraints are inequalities involving x and y.

For a feasible region, the optimum value usually occurs at a corner point.
Practice:
If Z = 3x + 2y, find Z when x = 2 and y = 3.
Answer: Z = 3(2) + 2(3) = 12

13. Probability

Important Formulas

P(A) = Number of favourable outcomes / Number of total outcomes

P(A') = 1 - P(A)

P(A ∪ B) = P(A) + P(B) - P(A ∩ B)

P(A|B) = P(A ∩ B) / P(B)

If A and B are independent:
P(A ∩ B) = P(A)P(B)
Practice:
A fair coin is tossed once. What is the probability of getting Head?
Answer: 1/2
